# Fact Checker Agent

This is a LangGraph AI agent that provides fact checking capabilities using the
[CoPilotKit](https://github.com/IBM/coplilotkit) packages.

The agent is built using the [FactCheckerAgent](https://github.com/IBM/fact-checker-agent)
library, which provides a simple interface for checking facts and generating
natural language text based on the results of the fact checking.

The agent is designed to be used with the LangGraph AI platform, but it can also
be used standalone.
